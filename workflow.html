Use Case — In-Context Verse Jump
Preacher already on a chapter says “verse 20” or “jump to verse 20” — OCS stays in the current book/chapter
Actor
Preacher (or worship leader) during sermon
Precondition
A verse is already on screen (e.g. John 3:16) — context = book + chapter

Accepted phrases (same chapter)

verse 20
jump to verse 20
go to verse 20
verse twenty
skip to verse 20
turn to verse 20
Context
On screen
John 3:16 already displayed · currentRef = { book: John, chapter: 3 }
Speech
“verse 20”
Or “jump to verse 20” · Vosk → transcript
Pass 4
Context match
No book name → reuse current book/chapter · matchType: context_verse
Result
John 3:20
SQLite fetch → IPC → Speaker + General View
1

Establish context

Operator or voice already showed a full reference (e.g. “OCS John three sixteen”). currentRefState stores bookIndex + chapter + verse.

2

Hear short jump phrase

Preacher says “verse 20” or “jump to verse 20”. Word-numbers converted (“twenty” → 20). No book name required.

3

Pass 4 resolves against context

smartBibleMatch Pass 4 matches verse-only / jump-to-verse patterns and returns { bookIndex, chapter: 3, startVerse: 20, matchType: 'context_verse' }.

4

Display + keep context

John 3:20 pushed to displays. Context updated so the next “verse 21” also works. Feedback badge: “→ John 3:20 (in-context)”.

✅ Happy path: same book/chapter, new verse on screen < 3s
⚠️ No context yet: prompt “say a full reference first”
❌ Verse out of range: “No verse N in this chapter”
📎 Related: “chapter 4” jumps chapter in same book (verse 1)
